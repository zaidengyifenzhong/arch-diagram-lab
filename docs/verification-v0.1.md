## 尚未完成或不能证明

- 未进行人类读者理解实验、专家盲评或相对直接生成的效果比较。
- 没有完成 100 篇或八会议代表性采样。当前样本的年代、领域与来源明显不均衡。
- 语料校验器只检查数据结构和部分一致性，不重新证明原文解释、PDF 哈希或“已看图”声明；对照集缺少 PDF 总页数的上界字段。
- 图生成器不提供完整自动布局、全量碰撞检测或领域语义证明；复杂研究图仍需人工规划和核对。
- 教学图的大尺寸预览不代表目标会议最终排版已通过。实际论文需按目标栏宽重新检查字号、线条、图例及会务要求。
- Python 3.9+ 是代码支持基线，本次实际只在 Python 3.12 上运行；没有跨版本或跨操作系统测试结果。

## 发布原则

每阶段完成研究、交叉检查和测试后统一提交。原论文 PDF、原图像素、登录材料和私人信息不进入发布目录。若 GitHub 提交尚未核验，不以本地验收代替线上发布证明。
