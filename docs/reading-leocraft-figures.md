# LEOCraft：先固定比较条件，再区分目标网络与宿主成本

[返回固定样本目录](../catalog/README.md#reading-guide-atc2025-leocraft)

只用 [USENIX ATC 2025 正式 PDF《LEOCraft: Towards Designing Performant LEO Networks》](https://www.usenix.org/system/files/atc25-basak.pdf)定位图号：26个物理页（含封面），印刷页789–813。下文 `#page=` 均为 PDF 物理页；例如物理p11对应印刷798页，不应将798填入 PDF 页码跳转。

核验范围：保留既有正文19图（F1–F19）与附录10图（F20–F29）的初研状态，采用已有图号／页码记录及本轮提供的核对信息。本次网页工具因文件超过读取大小上限未能打开 PDF，未完成新的逐图视觉审核，也未换路线获取文件。因此不描述未经重新查看的配色或线型；初读不等于独立审核通过或实验复现。本页只提供原创文字与原文链接，不复制实验图、表、数据或 PDF。

## F11 → F12 → F13：先写每一对面板固定了什么

打开 [F11–F13（物理p11／印刷798）](https://www.usenix.org/system/files/atc25-basak.pdf#page=11)。三幅相邻图能组成解释链，但不是同一条件下重复做了三次实验。

- **F11(a/b)：总量相同，组织方式不同。** 22×72 与72×22都等于1,584颗卫星。先写轨道数和每轨卫星数，再问重新分配会怎样改变网络；不能仅由总数相同推断拓扑相同。
- **F12：先定位面板设置。** 特别是 F12(c) 固定72条轨道。转到 F13 前，重新抄下控制条件，不能把后者当作 F12(c) 的同条件复刻。
- **F13(a/b)：固定相位0.5，对比144与48条轨道。** 看的是南亚到北美同一对端点的20条最短路径；先核对端点相同，再比较轨道组织变化。
- **F13(a/c)：固定144条轨道，对比相位0.5与0。** 这次改变的是相位。不能将 (a/b) 的轨道数变化与 (a/c) 的相位变化揉成一个原因，更不能把这对端点的路径表现推广到全部站点对。

**练习：有人说“F13证明 F12(c) 中的现象完全由相位造成”，应先检查哪里？** 先查轨道数：F12(c)是72，F13(a/c)是144。后者在自己的条件下隔离相位变化，可以帮助理解可能机制，却不能充当同条件的复刻或排除其他因素的证明。再查端点与路径选择，避免把20条路径当作全网所有流量。

## F3 → F17：时间稳定性有适用边界

[F3（物理p7／印刷794）](https://www.usenix.org/system/files/atc25-basak.pdf#page=7)讨论单壳层中选定指标随时间变化有限。阅读时给结论补上“单壳层”和“这些指标”，不要写成所有 LEO 网络都可忽略时间变化。

到 [F17（物理p13／印刷800）](https://www.usenix.org/system/files/atc25-basak.pdf#page=13)，对象已经变成多壳层、带跨壳连接，并考虑无切换时的相对运动。练习：先圈出新引入的跨壳关系，再问原来单壳层结论依赖的条件是否仍成立。两图之间的研究对象发生变化，不能从 F3 直接推导 F17 的动态行为。

## F18／F19：目标 RTT 与运行模拟器所花时间

同在[物理p14／印刷801](https://www.usenix.org/system/files/atc25-basak.pdf#page=14)，这两幅图回答不同问题：

| 图 | 研究问题与参照 | 不应推出的结论 |
|---|---|---|
| F18 | 在相同站点对和壳层条件下，将目标网络 RTT 与 Hypatia 的结果比较。 | 模型间接近不等于在轨实测验证；也不是宿主仿真速度。 |
| F19 | 对另一组合成单壳规模工作负载，检查宿主运行仿真的用时。 | 不能当作 F18 那一组任务的运行成本，更不能说目标网络 RTT 因而同倍下降。 |

**练习：如果关心设计的网络是否让通信更快，先看哪幅；如果关心研究者多久能完成模拟，先看哪幅？** 前者先看 F18 的目标 RTT 及其参照，后者先看 F19 的宿主用时及合成规模设置。两幅都与“时间”有关，但对象、工作负载与证据意义不同。

可对照 [RHONE 导读](reading-rhone-figures.md)：其 F13 用 BUPT-1 实际在轨时延作参考；LEOCraft F18 的 Hypatia 参照则属于模型间比较。不能把两者说成同等实测验证，也不能仅按参照类型给整篇论文排可靠性名次。研究问题决定所需图组：设计参数怎样改变路径，需要控制条件下的对照；模型输出是否接近目标，需要合适的参考；工具能否扩展，则需要独立说明宿主成本。

原图再分发许可仍未核实，软件制品的 MIT 许可不等于论文图像许可。本次不改变既有初读状态、图库数量或固定样本覆盖口径。
